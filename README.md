# 開発指示書：MacBook中古価格の自律監視・分析エージェント（ローカル環境用）

私は現在、自身のパソコン（ローカル環境）からこのエージェントを起動しています。
私が「安くて状態の良いMacBook」を最速で購入できるよう、以下の要件を満たす自律監視・相場分析システムを、この環境内で設計・コード作成・テスト実行まで完全に完結させてください。

## 1. 開発の最終ゴール

特定の中古PC専門店からMacBookの価格情報を定期的に自動収集（スクレイピング）し、過去のデータから算出した「平均相場」よりも格安（例：20%以上安い）で、状態の良い商品が見つかった場合に、Discordなどの外部ツールへURL付きで自動通知するシステム。

## 2. 開発ロードマップ（ステップ順に進めてください）

### フェーズ1：情報収集（スクレイピング）スクリプトの作成

- 言語は **Python** を使用してください。
- ターゲット：まずはサイト構造が比較的安定している大手中古ショップ（例：「じゃんぱら」や「パソコン工房」など、エージェントが取得しやすいと判断したサイト）を1〜2つ選定してください。
- 取得データ：「商品名」「スペック（M1/M2、メモリ容量など）」「価格」「状態ランク（A品、B品など）」「商品URL」。
- ライブラリ：必要に応じて `requests` や `BeautifulSoup`、またはブラウザを自動操作する `Playwright` などを自律的にインストールして使用してください。

### フェーズ2：相場分析と「お買い得度」の判定ロジック

- 取得したデータを、同じフォルダー内に `macbook_data.json` または `csv` 形式で蓄積できるようにしてください。
- 蓄積されたデータから、モデルごとの「平均価格」を自動で計算するロジックを作ってください。
- 新着商品が「平均価格よりも〇〇%以上安い」場合のみを「お買い得」と判定する条件分岐を組み込んでください。

### フェーズ3：外部への自動通知テスト

- 条件に合致したお買い得商品が見つかった際、Discordの「Webhook」機能、またはLINEなどの使いやすい通知ツールを使って、メッセージと商品URLがスマホにプッシュ通知される仕組みを作ってください。
- テスト用に、ダミーのデータを使って通知が正しく飛ぶか確認するスクリプトも用意してください。

## 3. エージェントへの行動ルール

1. **計画の提示**: 新しいフェーズに移る際は、これから行う作業内容をログとして画面に明示してください。
2. **自律エラー修正**: ライブラリの不足やスクレイピング時のエラー（データが取れない等）が発生した場合は、原因を自ら分析し、コードを修正して再実行するループを自動で回してください。
3. **安全第一**: サイトに負荷をかけないよう、ページを読み込む際は必ず数秒の「待ち時間（スリープ）」を入れるコードにしてください。

まずは、フェーズ1の「ターゲットにする中古ショップの選定」と「Pythonの環境確認」から開始してください。
